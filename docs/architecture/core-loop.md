# Core Gameplay Loop & Economy Architecture

이 문서는 StudyGame의 2대 축인 **[2D 가상 OS]**와 **[3D 실시간 결계 아레나]** 간의 전이 규칙 및 경제 교환비(Economy Loop)를 정의하는 아키텍처 명세서다.

---

## 1. 2원화 코어 루프 구조

```text
[Loop 1. 2D 가상 OS 정비] (비전투/분석)
   │  - 다이어리: 퀘스트 및 시나리오 단서 확인
   │  - UWB (인게임 브라우저): 외부 교과 학습 문서/인강 스트리밍
   │  - AI Q&A 디코더: 획득한 암호 조각을 개념 소켓(Socket)으로 해독/장착(Loadout)
   │  - 조력자 NPC 파티 편성 (에피소드 테마 과목 동행)
   ▼
[Loop 2. 3D 실시간 결계 아레나] (전투/실행)
   │  - 라미고등학교 기이 공간 진입 ('다이브' 버튼)
   │  - 별의 커비 디스커버리 스타일의 유연한 3인칭 뷰 및 3~4버튼 직관 조작
   │  - 방사형 사물 결계 아레나에서 괴이(Anomaly Creature)와 실시간 액션
   ▼
[Loop 3. 자물쇠-열쇠 기믹 파훼] (교과 논리 검증)
   │  - 몬스터 물리 패턴(분열, 반사, 돌진 등) 관찰 후 약점 추론
   │  - 개념 소켓이 장착된 뼈대 스킬로 타격 ➔ 그로기(인식 붕괴) 유도
   ▼
[Loop 4. 구출 및 공간 정화] (성취감/카타르시스)
   │  - 보스 격파 시 사물 결계가 픽셀로 분해되며 '가상 실외(푸른 하늘/잔디)'로 정화
   │  - 갇혀 있던 동급생 NPC 구출 및 '암호화된 과목 데이터 조각' 획득
   ▼
[Loop 5. 복귀 및 SOS 학습 루프] (루프 순환)
      - 2D 가상 OS로 귀환
      - 실패 시: 가상 SNS(라미-톡)에 공략 힌트 및 퀴즈(SOS) 노출 ➔ 연산 포인트 획득
      - 연산 포인트를 소모해 데이터 조각을 신규 개념 소켓으로 해독 ➔ [Loop 1 재진입]
```

## 2. 경제 교환비 (Economy Loop) 및 재화 흐름

| 단계 | 입력 (소모) | 처리 시스템 | 출력 (보상) |
| :--- | :--- | :--- | :--- |
| **전투 (3D)** | 컨트롤 (피지컬/스킬) | 괴이 격파 및 NPC 구출 | **암호화된 과목 데이터 조각** (미완성 소켓) |
| **학습 (2D)** | SNS 힌트 퀴즈 / 학습 활동 | 가상 SNS (라미-톡) | **연산 포인트 (Computation Point)** |
| **해독 (2D)** | 데이터 조각 + 연산 포인트 | AI Q&A 디코더 | **개념 소켓 (완성품 스킬 룬)** |
| **스펙업 (2D)** | 개념 소켓 장착 (Loadout) | 뼈대 스킬 인벤토리 | **3D 필드 전투력 및 기믹 파훼력 상승** |

### 맹점 방어 및 보상 체계 (Pacing & Abuse Prevention)
- **온전한 메인 보상 보장 (박탈감 방지):** 메인 스토리 에피소드는 1트라이 실패나 잦은 사망 여부와 무관하게 클리어 시 스토리 진행, 기본 재화, 구출 학생, 기본 아티팩트를 100% 온전히 지급한다.
- **특별 아티팩트의 다중 획득 경로 (영구 결손 방지):**
  - 초행 1트라이 성공 시: 특별 아티팩트(통찰의 증명) 및 명예 보너스 즉시 지급.
  - 초행 실패 시의 대체 획득:
    1. **가상 OS '모의고사' 앱 (도전형):** 이미 클리어한 보스를 훈련/도전 모드(등급컷)로 재도전하여 상위 랭크 달성 시 동일한 특별 아티팩트 및 칭호/스킨 획득 가능.
    2. **'손상된 아카이브 복원' (재화형 싱크홀):** 잉여 연산 포인트 또는 정크 데이터를 지불하여 미획득 아티팩트(카세트테이프 BGM, 설정집, 다이어리 테마)를 즉시 잠금 해제(복원).
- **SOS 구원 힌트 (Opt-in & 페널티 배제):** 사망(Game Over) 시에만 SNS에 알림 뱃지가 뜨며, 힌트 열람을 '벌칙'이 아닌 '치트키'로 인식하도록 감점 페널티를 없애고 퀴즈를 풀면 즉시 강화용 연산 포인트를 공급한다.
- **하드 캡 (Hard Cap) & 정크 데이터:** 에피소드별 동기화율 및 포인트 최대 한도를 두어 초반 무한 파밍을 방지하고, 초과분은 '정크 데이터'로 전환되어 다크웹 상점(1회성 글리치 인젝터, B급 해적판 시뮬레이터 티켓)에서 소모된다.

## 3. 내러티브 및 페르소나 제어

- **침묵하는 관찰자 (Silent Protagonist):**
  - 주인공 캐릭터는 독백, 속마음 지문, 직접 대사가 일절 없다.
  - 모든 상호작용은 2인칭 행동 선택지(예: `[과거 일이 기억나지 않냐고 묻는다]`, `[다친 데 없으니 넘어가자고 말한다]`)로만 구성된다.
  - 내러티브 정보 전달은 스마트폰 시스템 로그(예: `[Sync +2% : 생존 데이터 갱신 완료]`)를 통해 건조하고 담백하게 표현한다.
- **NPC 동기화율 (Sync):**
  - 루프 시 세상은 리셋되지만, 스마트폰이 NPC의 무의식에 백도어로 접속해 이전 루프의 감정적 잔재(Sync)를 유지한다.
  - 동기화율이 오르면 해당 과목의 전투 패시브 스킬이 해금된다.
